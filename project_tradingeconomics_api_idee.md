Am 03.08.2026 vom User als Idee für die Zukunft aufgeworfen: TradingEconomics-API-Zugang für 149$/Monat statt der aktuellen kostenlosen `WebFetch` auf die öffentliche tradingeconomics.com/calendar-Seite (siehe [[feedback_session_update]] Schritt 4).

**Anlass:** Am selben Tag zeigte der WebFetch-Kalender-Scrape zwei Fehler (fake "Actual"-Wert vor Veröffentlichung, fehlender Freitag-NFP-Termin) — User musste die Wochenübersicht manuell nachliefern.

**Why:** Eine echte API würde strukturierte Live-Daten statt einer möglicherweise gecachten/unvollständigen Webseite liefern.

**Status:** Nicht entschieden, kein Kauf-Commitment. Bewusst als "später prüfen, falls sich Fetch-Fehler häufen" eingestuft — der heutige Vorfall war der erste dokumentierte Fall, der Tweet-Kalender-Cross-Check (Schritt 2) hat die Lücke aufgefangen.

**How to apply:** Bei zukünftigen wiederholten Kalender-Fetch-Fehlern diese Idee wieder aufgreifen und dem User aktiv vorschlagen, statt sie zu vergessen.
